开始使用

三步完成配置

1

下载并安装

按系统下载对应的安装版，安装后打开 CC Switch。

2

添加供应商

在“添加供应商”中选择 CodexZH 或 CcodeZH 预设，也可以通过网站上的导入链接一键导入。

3

填入 Key 并启用

粘贴你自己的 API Key，保存后启用，对应客户端的配置会自动写好。

Windows

  1. 普通电脑选 x64，骁龙等 ARM 设备选 ARM64。
  2. 双击 MSI，按提示完成安装。
  3. 如出现 SmartScreen 提示，点“更多信息 → 仍要运行”。

macOS

  1. DMG 同时支持 Apple 芯片和 Intel。
  2. 打开 DMG，把 CC Switch 拖入“应用程序”。
  3. 若提示无法验证开发者，在“系统设置 → 隐私与安全性”中点“仍要打开”。

Linux

  1. Debian / Ubuntusudo apt install ./CC-Switch-*.deb
  2. Fedora / RHELsudo dnf install ./CC-Switch-*.rpm

配置方法与模型说明见 CodexZH 文档。
